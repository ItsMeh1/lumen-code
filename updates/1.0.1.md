# Lumen Code | Version 1.0.0 & 1.0.1
## Whats new in this version?
- **Autocomplete:** Lumen Code now features a basic autocomplete to finish simple lines of code, not as good as VSCode's though.
- **Non-Static Runtime:** Lumen code lets you run tons of different kinds of languages. More on that in the Supported Languages section.
- **Projects:** Don't lose your code, save it in a Project and you can come back to it later.

## Supported Languages

| Langauge | Provider |
| -------- | -------- |
| HTML   | Locally sandboxed   |
| CSS    | Locally sandboxed   | 
| Javascript | Locally sandboxed |
| Typescript | CDN |
| Python | Pyodide |
| Lua | Fengari |
| SQL | AlaSQL |
| Ruby | ruby.wasm |
| PHP | php-wasm |
|C & C++ | JSCPP (won't run everything) |
| Markdown | Locally rendered as a page |
| SVG | Locally rendered & shown in preview tab |
